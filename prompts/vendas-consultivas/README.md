# Prompts para Vendas Consultivas com IA

Coleção de prompts desenvolvidos para criação de agentes inteligentes focados em vendas, qualificação de leads, automação comercial e gestão de oportunidades.

## Objetivos

* Criar assistentes de vendas mais eficientes
* Melhorar a qualificação de leads
* Estruturar processos comerciais com IA
* Aplicar frameworks modernos de vendas
* Demonstrar aplicações práticas de Engenharia de Prompt
